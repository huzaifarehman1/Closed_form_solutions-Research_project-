### Results of the Greedy Layer-Wise Approach

We first investigated a greedy approach in which each layer was trained independently using the closed-form solution of linear regression. Specifically, given an input representation \(X\) and target \(Y\), the weight matrix \(W\) for each layer was obtained by solving the linear least-squares problem

$$
W^* = X^+Y,
$$

where \(X^+\) denotes the Moore–Penrose pseudoinverse. The resulting linear transformation was then passed through a nonlinear activation function to obtain the representation for the subsequent layer:

$$
V = \sigma(XW^*).
$$

This procedure was repeated layer by layer, with each layer being optimized to predict the original target \(Y\) rather than being optimized jointly with the subsequent layers.

Although this approach provided a closed-form optimization procedure for each individual layer, it failed to produce a useful multi-layer representation. The primary issue was that the optimization objective of each layer was not aligned with the objective of the complete neural network. Each layer was forced to independently approximate \(Y\), rather than learning a representation that would be useful for the layers that followed.

Furthermore, the linear regression solution at an individual layer does not explicitly account for how its output will be transformed by subsequent layers and nonlinear activation functions. Consequently, information that may have been useful for the overall network could be discarded when the layer was optimized solely for its immediate prediction of \(Y\).

In the experimental setting considered here, this problem was particularly apparent when the representation was constrained such that a single learned weight was effectively associated with each individual feature. This substantially reduced the representational capacity of the layer. Instead of learning a rich transformation in which multiple input features could jointly contribute to multiple hidden dimensions, the greedy optimization produced a restricted representation. As a result, important relationships between features could not be adequately encoded in the intermediate representation.

More fundamentally, the greedy procedure prevents the optimization from capturing dependencies between layers. In a conventional neural network, the parameters of earlier layers are optimized according to how changes in their representations affect the final output after passing through all subsequent layers. In contrast, our greedy approach optimized each layer independently and therefore did not expose the optimization procedure to these downstream relationships.

Thus, while the closed-form linear regression solution successfully solves the optimization problem for an individual linear layer, directly applying it in a greedy layer-wise manner does not necessarily yield a solution for the corresponding nonlinear multi-layer network. The experiment demonstrates that obtaining a closed-form solution for each component independently is insufficient when the components are coupled through nonlinear transformations. A successful analytical solution must instead account for the interactions between the parameters and representations across the entire network.
